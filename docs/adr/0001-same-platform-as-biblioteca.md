# Built like Biblioteca: a static app on her iPad, data on the device, public repo on free GitHub Pages

This is the same choice and the same reasons as Biblioteca (see its ADRs 0001–0003): her iPad is the device, there is no server, the weekly backup is the safety net, and the public repo hosts free. Her income figures never go into the repo. Saving is coalesced: a burst of changes is written once.
