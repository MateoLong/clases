# Tarifas and Horarios fijos change from a date, and money already made never moves

A raise or a new weekly time takes effect from a date she picks, so earlier Clases keep their old Tarifa and day. When the date is today and today's Clase of that slot has already started, it stays with the old slot and the change starts tomorrow. Archiving cuts at the current moment in the same way. The independent verifier found the earlier version (cut at yesterday) dropping a class already given today from her earnings. The tests now pin this down.
