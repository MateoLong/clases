# A Clase counts as Ganado once its end time passes, not when it is paid

The owner chose this (2026-10-03) over "classes given only" and "only what was paid". Payments are recorded separately, so Te deben = Ganado − Pagos. The consequence is that if she bills monthly, Te deben always includes the current month's classes so far. A class cancelled with "se cobra" also counts.
